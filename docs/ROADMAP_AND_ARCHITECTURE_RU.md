# Архитектура и дорожная карта: AI Assistant (MooMoo) для Scrap Mechanic

## Концепция проекта

Baby Woc по имени **MooMoo** — интерактивный внутриигровой AI-компаньон в Scrap Mechanic.
Игрок общается с ним через команду `/aiask <сообщение>` (в будущем — через диалоговый GUI).
Коровка отвечает от первого лица через языковую модель (OpenRouter / GPT-4.1-mini) и может инициировать безопасные, строго валидируемые действия в игровом мире.

Главный принцип: AI опирается на **живое состояние мира** (`liveContext`), а не на догадки или статическую базу файлов. Если действие невозможно — честно сообщает об этом.

## Разрешённые действия (Action Protocol)

AI возвращает строгий JSON-ответ:
```json
{
  "reply": "Сейчас сделаю ночь!",
  "actions": [
    {
      "name": "set_time_of_day",
      "args": { "time": 0.95 }
    }
  ]
}
```

Серверная часть мода (`Game.sv_executeAiActions`) валидирует имя действия и аргументы по белому списку:
* `call_companion`, `dismiss_companion` — вызов/роспуск коровки через `BabyWocManager`.
* `spawn_ai_cow`, `despawn_ai_cow` — спавн/деспавн тестового NPC.
* `set_ai_mode_follow`, `set_ai_mode_stay`, `set_ai_mode_come` — режимы поведения.
* `set_time_of_day`, `set_time_progress` — управление временем суток.
* `activate_quest`, `complete_quest`, `abandon_quest` — квестовые действия.
